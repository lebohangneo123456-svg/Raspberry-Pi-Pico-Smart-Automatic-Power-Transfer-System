## How to publish

1. Create a public repo with the exact name above.
2. Don't initialize it with a separate README or license.
3. Extract the provided ZIP and upload **the folder contents** (all subfolders, README, license and .gitignore), rather than uploading only the ZIP.
4. Commit and view the repository home page; confirm the Mermaid block diagram and four screenshots render.
5. Add topics in the About pane.
6. When you capture **genuine** oscilloscope traces, add them to `Images/` and reference their exact filenames in `README.md`.

## Accuracy note
The present circuit/simulation has two separately controlled indicator lamps. It is not yet verified as an actual one-load automatic transfer installation. Keep this limitation visible in the repository until the hardware/schematic is revised and tested.
